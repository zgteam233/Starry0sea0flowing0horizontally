# 花至荼蘼 · 同人视觉小说

> 基于国产漫画/动画 **《有兽焉》**（作者：靴下猫腰子）的同人原创视觉小说。
>
> 白麒麟 **四不相** 与灰麒麟 **四不遇**——两个「死不相遇」的灵魂，跨越一万年的执念与守望。

本项目是一个**纯标准 C++（C++23）文字冒险游戏引擎 + 完整可玩的序章「咫尺天涯」**，零第三方依赖，跨平台（Windows / Linux / macOS）。

---

## 一、项目结构

```
huazhitumi/
├── CMakeLists.txt          # CMake 构建（通用）
├── README.md
├── src/
│   ├── main.cpp            # 程序入口
│   ├── config.h            # 颜色、常量、角色配色（全局配置）
│   ├── input.h/.cpp        # 跨平台按键输入（Windows conio / POSIX termios）
│   ├── renderer.h/.cpp     # 文本演出（打字机/颜色/居中/清屏）+ 配图接口
│   ├── script.h            # 剧情脚本数据模型 + 流式构建器
│   ├── map.h/.cpp          # 可走动探索地图（终端字符俯视图）
│   ├── save.h/.cpp         # 多槽存档系统（纯文本格式）
│   ├── game.h/.cpp         # 主循环、标题菜单、存档菜单、剧情状态机
│   ├── status.h/.cpp       # 角色档案、属性、背包与物品数据
│   ├── prologue.h/.cpp     # 序章「咫尺天涯」完整剧情脚本
│   ├── cover_art.h         # 开场字符画数据（tools/cover_art.py 自动生成）

├── assets/images/          # 配图资源（开场原图 + 字符画预览）
└── saves/                  # 存档目录（运行时自动生成）
```

## 二、编译与运行

> 本项目需要支持 **C++23** 的编译器，以及 [CMake](https://cmake.org/) 和 [Ninja](https://ninja-build.org/)（Windows 构建脚本使用 Ninja）。中文源码统一采用 **UTF-8 编码**。

### 方式 A：下载预编译包 (推荐)

目前仓库尚未发布预编译包。请使用下面的构建方式自行编译；发布包含预编译包的正式版本后，本节会补充下载链接与校验方式。

### 方式 B：PowerShell 构建脚本

在仓库根目录打开 PowerShell：

```powershell
pwsh .\build.ps1
```

脚本会清理并重新生成 `build/`，使用 CMake + Ninja 编译 Release 版本。运行：

```powershell
.\build\huazhitumi.exe
```

首次使用前，请确认已安装 CMake、Ninja 和支持 C++23 的编译器，并将它们加入 `PATH`。

### 方式 C：手动使用 CMake

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

运行：

- Windows：`.\build\huazhitumi.exe`
- Linux/macOS：`./build/huazhitumi`

若系统已配置 CMake 可用的编译器，但未安装 Ninja，也可以移除 `-G Ninja`，改由 CMake 根据环境选择默认生成器。

## 三、操作说明

| 按键 | 作用 |
| --- | --- |
| `回车` / `空格` | 推进剧情（打字机状态下：先瞬间显示完本句） |
| `↑` / `↓` | 选项、菜单中移动光标 |
| `回车`（选项/菜单中） | 确认当前项 |
| `1` ~ `9` | 选项/菜单快速选择 |
| `S` | 快速存档 |
| `Esc` | 打开系统菜单（继续 / 存档 / 读档 / 回到标题 / 退出） |
| `Esc`（存档菜单中） | 取消返回 |

### 探索地图（序章）

序章在剧情之间会进入**俯视地图**，可自由走动：

| 按键 | 作用 |
| --- | --- |
| `方向键` / `WASD` | 移动四不相 |
| `回车` / `空格` | 站在物件 / 门上时互动（打开门、查看床桌柜等） |
| `鼠标左键` | 点哪走哪（自动寻路，点到门上就直接走到门口） |
| `数字键 1~9` | 直达：自动走到第 N 个可互动地点（门就直接走到门上） |
| `Esc` | 打开系统菜单（存档 / 读档 / 回到标题 / 退出） |

**宿舍**是一间 40×16 的房间，墙上有两扇门（都在下墙）：正中是**正门**，偏右是**杂物间的门**。门是出口，可以走上去、按回车打开。

**深夜宿舍**（上床睡觉后）是同一间屋子的深夜版本：**四不遇会出现在地图上**，自己从门口走进来、绕到床边说话、再走回门边离开——你不用操作，看着就行；期间也可以用方向键在旁边走动。

其余地图（天庭）上，当前目标地点会高亮为金色，走到跟前按回车进入；玩家标记为全角 `＠`。

## 四、存档系统

- 存档保存在 `saves/` 目录，共 **6 个槽位**，纯文本 `.sav` 文件。
- 记录内容包括：当前剧情节点、全局变量（选择分支 flag）、章节、场景、时间戳。
- 标题画面可「新的开始 / 继续游戏（最近存档）/ 读取存档」。

## 五、引擎框架（如何扩展）

游戏采用「**剧情脚本 → 状态机解释执行**」架构，扩展新章节只需：

1. 新建一个 `xxx.cpp`，仿照 `prologue.cpp` 用 `ScriptBuilder` 编写剧情。
2. 在 `game.cpp` 的 `buildChapter()` 里按章节名分发。

剧情脚本支持以下节点（见 `script.h`）：

| 节点 | 说明 |
| --- | --- |
| `say(说话人, 台词)` | 对白（可带说话人/文本颜色） |
| `narr(文本)` | 旁白 / 心理描写 |
| `scene(标题, 配图id)` | 场景切换（清屏 + 标题） |
| `choice(提示, 选项列表)` | 选项分支 |
| `label(名)` / `jump(名)` | 跳转标签 / 无条件跳转 |
| `setFlag(键, 值)` | 设置全局变量 |
| `branch(键, 期望值, 目标)` | 条件跳转（变量等于期望值则跳转） |
| `map(地图id, x, y, 出口列表)` | 进入可走动地图，走到出口地点按回车触发对应 label |
| `mapWithActors(...)` | 同上，并带上「自己会动的地图角色」（深夜宿舍的四不遇） |
| `end(标题, 文本)` | 结局画面 |
| `chapterEnd(标题, 文本)` | 章节结束画面 |

### 地图角色（会自己走路、说话的 NPC）

深夜宿舍里的四不遇就是用这个做的。每个角色有一串 `steps`：

| 步骤 | 写法 | 说明 |
| --- | --- | --- |
| 走 | `actMove(x, y)` | 一格一格走过去，自动绕开玩家 |
| 说 | `actSay("四不遇", "哥……", color)` | 出一句对白（自动显示，不停等按键） |
| 旁白 | `actNarr("……")` | 出一句旁白 |
| 消失 | `actDisappear()` | 从地图上消失 |
| 结束 | `actFinish()` | 脚本走完，回到正常地图 |

> 序章中已内置一个玩家内心选择（文书阁），并演示了「选择 → 变量 → 后续分支」的完整链路；这一机制正是后续「伪·坏结局 · 温茶」等分支结局的基础。

## 六、配图

开场画面（序章 · 咫尺天涯）有一张配图，但终端里没法贴 PNG，所以做成了**字符画**：把画直接换算成「上半块 ▀ + 24bit 真彩色」的字符格，一个字符格子表示上下两个像素（前景色画上半、背景色画下半）。

- `assets/images/prologue_cover.png`：开场原图（两只对视的麒麟），这是唯一的一张源图。
- `src/cover_art.h`：由 `tools/cover_art.py` 生成的字符画数据，提供两个尺寸：
  - **92 列 × 34 行**（实际表现 92×68 像素）—— 窗口 ≥ 92 列、≥ 37 行时使用；
  - **76 列 × 24 行** —— 窗口装不下大图时自动降级，保证不折行、不滚动。
- `assets/images/prologue_cover_preview.png`：字符画的实际观感预览（按字符格的 1:2 比例放大）。

`Renderer::showImage(imageId)` 的行为：`prologue_cover` → 按窗口大小选大图/小图并居中打印，等玩家按键后清屏继续；窗口太小则打印一行提示跳过；其它 id → 静默跳过。
将来接入图形后端（SDL2 等）时，只需改这一个函数，**剧情脚本无需任何改动**。

### 重新生成字符画

```bash
python tools/cover_art.py                      # 用默认源图，76/92 两种尺寸
python tools/cover_art.py 源图.png 76 100      # 指定源图与列数
```

脚本会自己找到画面的主体范围、上下居中裁切（宁可切掉空白底），并在缩小时做「墨线保留」降采样，让细线不被平均成糊块。

> `tools/` 里的脚本是制作工具，**不参与编译**，游戏本身零依赖。若终端不支持真彩色、画面变成一片灰块，可用 `HZ_COVER_PLAIN=1` 临时跳过配图（剧情照常）。

## 七、关于原作与设定

- 本作角色与世界观基于《有兽焉》：四不相（白麒麟，双角四耳，前爪后蹄，青色绒毛）、始麒麟/玉麒麟、天禄（小蓝圈）、辟邪（小梅花）、帝江、烛龙、四不像（戴面具的鹿）等。
- 核心原创设定：四不相「想要个弟弟」的执念结晶 —— 女娲以「源」泥土捏成的灰麒麟 **四不遇**。
- 阳魂（能力·天庭傀儡）/ 阴魂（记忆·浮梦中的魂）二分，对应「找回记忆」主线与「花尽 / 温茶」等多结局走向。
